# AGT AdBlock

Android için sistem genelinde reklam ve takip alan adı filtreleme uygulaması.

## Hedefler
- Root gerektirmeyen Android VPNService tabanlı DNS filtreleme
- Sistem genelinde alan adı engelleme
- Türkçe arayüz ve uygulama bazlı istisnalar
- GitHub Actions ile otomatik APK derleme
